# Дополнительные проверки v0.6.12 RC2

1. Выставить прозрачность капсулы 50–60%. Убедиться, что она видна в мини-режиме, а полный режим полностью непрозрачен.
2. Несколько раз развернуть и свернуть плеер: переход прозрачности плавный и без рывков, позиция не меняется.
3. Проверить темы «Светлая», «Тёмная», «По окружению», «По обложке»: раскрытый фон непрозрачный в каждой из них.
4. Открыть настройки при раскрытом плеере, изменить прозрачность, сохранить: полный режим остаётся непрозрачным.
5. Проверить подсказки всех кнопок: короткие, Play/Pause меняется с состоянием, повтор остаётся понятным.
6. Убедиться, что после нескольких циклов повторения `repeat.log` не растёт, если диагностика не включена.
7. Повторить стандартные проверки управления, громкости, перемотки, скрытия и Win+D.

# План проверки перед релизом v0.6.11

Окружение: Windows 11, Яндекс Музыка (указать версию), монитор (указать DPI), режимы темы/обоев. Результат для каждой проверки: **OK / FAIL / PARTIAL**. При сбое приложить шаги воспроизведения и версии.

## Сборка и запуск

- [ ] `dotnet restore` и `dotnet build -c Release` завершаются без ошибок.
- [ ] Запуск через Visual Studio и отдельно из опубликованной папки без Visual Studio.
- [ ] Иконка EXE, трея и окна настроек отображается корректно.
- [ ] Закрытие из трея завершает процесс без зависаний.

## Медиасессия

- [ ] Мини-режим: назад, Play/Pause, вперёд без самопроизвольного раскрытия.
- [ ] Полный режим: обложка, название и исполнитель актуальны после 5 переключений.
- [ ] Клик/перетаскивание прогресса перематывает, позиция продолжает идти после 10 секунд.
- [ ] Переключение Play/Pause сразу меняет значок; на паузе прогресс стоит.
- [ ] Громкость Яндекс Музыки: клик, drag и колесо. Системная громкость не меняется.
- [ ] Нажатие на обложку открывает Яндекс Музыку, если клиент запущен.
- [ ] Закрытие и новый запуск Яндекс Музыки: виджет исчезает и переподключается (при включённом правиле).

## Повтор трека — критическая регрессия

- [ ] Включить повтор: полная кнопка остаётся подсвечена **после ухода курсора**.
- [ ] Свернуть и раскрыть плеер 5 раз: кнопка повтора по-прежнему подсвечена.
- [ ] При повторе в **мини-капсуле** виден маленький постоянный значок повтора.
- [ ] Дождаться минимум 3 повторов одной песни: она перезапускается, не скачет между другими.
- [ ] Ручной Next/Previous при включённом повторе работает, без лавины команд.
- [ ] Выключить повтор: подсветка и индикатор в мини-капсуле исчезают.
- [ ] Включить повтор, остановить/запустить Яндекс Музыку — нет аварий.
- [ ] Проверить отсутствие бесконечных повторных попыток при неподдерживаемой команде.

## Windows и оформление

- [ ] Плавное раскрытие и сворачивание без изменения нижней правой точки.
- [ ] Мышь проходит через прозрачные зоны большого HWND в капсуле.
- [ ] Win + D, Win + M, правый край панели задач не прячут виджет без причины.
- [ ] Ручное скрытие в трей сохраняется (не «самовосстанавливается»).
- [ ] Светлый и тёмный фон, смена окружения и обоев, отсутствие мерцания.
- [ ] Настройки: тема, предпросмотр, отмена/сохранение, формы и PNG-наборы.
- [ ] Поведение на двух мониторах и при масштабировании Windows 125% или 150% (если доступно).

Перед отметкой `v1.0` проверьте, что права на все включённые PNG подтверждены и лицензионные файлы добавлены.
