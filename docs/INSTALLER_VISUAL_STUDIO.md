# Публикация YMusic Mini 0.6.12 из Visual Studio + установщик EXE

## 1. Публикация программы в Visual Studio

1. Распакуйте ZIP в обычную папку, например `D:\Projects\YMusicMini`.
2. Откройте `YMusicMini.csproj` в Visual Studio с .NET 10 SDK и нагрузкой **Разработка классических приложений .NET**.
3. В обозревателе решений щёлкните **правой кнопкой по проекту YMusicMini → Опубликовать (Publish)**.
4. Выберите существующий профиль **Win-x64-Installer** (он находится в `Properties/PublishProfiles/Win-x64-Installer.pubxml`).
   Если профиль не появился, закройте/откройте проект или настройте профиль **Папка / Folder** со значениями:
   - Конфигурация: `Release`;
   - Целевая среда: `win-x64`;
   - Развёртывание: `Self-contained` / **Автономное**;
   - Обрезка (trimming): **выключена**;
   - Одиночный файл: **выключен**.
   - Папка назначения: `publish\win-x64` относительно корня проекта.
5. Нажмите **Опубликовать / Publish**. Дождитесь сообщения об успехе.
6. Проверьте, что существует `publish\win-x64\YMusicMini.exe`; запустите этот файл отдельно для проверки управления музыкой. Не запускайте exe из `bin\Release` для тестирования установщика.

## 2. Компиляция установщика

1. Установите Inno Setup с официального сайта: https://jrsoftware.org/isinfo.php
2. Запустите **Inno Setup Compiler** и откройте `installer\YMusicMini.iss`.
3. Нажмите **Build → Compile** (Ctrl+F9).
4. Результат: `artifacts\installers\YMusicMini-Setup-0.6.12.exe`.
5. Если появится ошибка `Source file does not exist` / `No files found matching`, вернитесь к шагу 1 и опубликуйте приложение в `publish\win-x64`.

Альтернативно можно запустить из терминала Visual Studio: `powershell -ExecutionPolicy Bypass -File .\scripts\Build-Installer.ps1`. Сценарий сначала выполняет dotnet publish, затем компилирует Inno Setup и проверяет EXE.

## 3. Тест настоящей установки (обязательно)

- Закройте плеер до установки.
- Запустите `YMusicMini-Setup-0.6.12.exe`.
- Проверьте, что программа появилась в меню «Пуск» и в «Установленные приложения».
- Запустите из меню «Пуск». Проверьте повтор, оформление, громкость, настройки, трей.
- Убедитесь, что программа установлена для текущего пользователя без запроса прав администратора.
- Удалите программу через «Установленные приложения». Проверьте, что ярлыки и файлы программы удалены.
- Настройки в `%AppData%\YMusicMini` преднамеренно сохраняются при удалении. При переустановке могут примениться старые настройки.

## 4. GitHub через Visual Studio

1. **Git → Создать репозиторий Git** / Git → Create Git Repository.
2. Выберите GitHub, войдите в аккаунт, имя `YMusicMini`; сначала **Private** для проверки, затем поменяйте на Public.
3. Перед публикацией посмотрите в Git Changes, что `publish`, `artifacts`, `bin`, `obj`, `.vs` не отслеживаются (их исключает `.gitignore`).
4. Выполните Commit и Push/Publish; убедитесь, что GitHub Actions выполнил Windows Release build.
5. На сайте репозитория откройте **Releases → Draft a new release**, создайте тег `v0.6.12`, прикрепите `YMusicMini-Setup-0.6.12.exe`.
6. Добавьте краткое описание функций и системных требований, ссылку на исходники и примечание: приложение неофициальное, не связано с Яндексом.
7. До публичного релиза выберите лицензию для исходников (например MIT, если хотите разрешить свободное использование). Убедитесь, что права на все изображения позволяют их распространение.

## Возможные предупреждения

- Неподписанный EXE может вызвать Windows SmartScreen «Неизвестный издатель». Не пытайтесь обходить защиту у пользователей: для доверенного релиза нужна подпись кода; начальный личный тест можно выполнить на своём устройстве.
- Self-contained сборка включает .NET 10, поэтому файл установщика может быть заметно больше исходного ZIP.
- Не публикуйте `settings.json`, `repeat.log`, файлы `bin/obj` и токены.
- Нет встроенного автообновления: при следующем релизе увеличьте версию в .csproj и `installer/YMusicMini.iss`, сохранив `AppId`.
- Данный архив содержит исходники и сценарий для создания установщика; готовый Windows-инсталлятор ещё требуется собрать и проверить на Windows.
