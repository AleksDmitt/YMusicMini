# YMusic Mini

**Неофициальный мини-плеер Яндекс Музыки для Windows 11 на C# / WPF.**

Приложение работает через системные медиасессии Windows и Core Audio. Не запрашивает логин, пароль или токен Яндекс Музыки. Проект не связан с Яндексом и не является официальным клиентом.

> **Статус:** v0.6.12 — готовится первый публичный релиз. Поведение основных функций проверено пользователем на Windows; установщик следует отдельно собрать и протестировать.

## Возможности

- Мини-капсула с настраиваемой прозрачностью и полностью непрозрачный раскрытый плеер; плавная анимация с неподвижной точкой закрепления.
- Play/Pause, предыдущий/следующий трек, обложка, название, прогресс и перемотка.
- Громкость приложения: щелчок по шкале, перетаскивание, колесо мыши.
- Локальный повтор одной песни — **экспериментальная функция** на базе команд Media Control. Не бесшовный; может пропускать последние ~2 секунды.
- Постоянная индикация повтора в полном режиме и значок активного повтора на капсуле.
- Системный трей, горячие клавиши, закрепление, автоматическая видимость.
- Темы Windows, по активному окну, по окружению и по обложке; градиенты и пользовательские наборы кнопок.

## Требования

- Windows 11 (ориентир; другие версии Windows с поддержкой используемых API требуют проверки).
- .NET 10 SDK для сборки и Visual Studio с компонентом **Разработка классических приложений .NET** (WPF), либо `dotnet` CLI.
- Установленное приложение Яндекс Музыки, публикующее медиасессию Windows.

## Сборка

```powershell
dotnet restore .\YMusicMini.csproj
dotnet build .\YMusicMini.csproj -c Release
```

Запуск отладочной версии в Visual Studio: откройте `YMusicMini.csproj` и нажмите **F5**.

Для публикации и установщика Windows x64 используйте готовый профиль Visual Studio `Win-x64-Installer` и файл `installer/YMusicMini.iss`. Подробности: **[docs/INSTALLER_VISUAL_STUDIO.md](docs/INSTALLER_VISUAL_STUDIO.md)**.

Для автоматической сборки из терминала Visual Studio:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Build-Installer.ps1
```

Публикуемую папку и работу собранного EXE следует проверить отдельно. Не считайте команду `publish` подтверждением совместимости со всеми компьютерами.

## Работа с данными

- Пользовательские настройки: `%AppData%\YMusicMini\settings.json`.
- Диагностика повтора выключена по умолчанию. При необходимости задайте `YMUSICMINI_REPEAT_LOG=1` перед запуском; журнал `%LocalAppData%\YMusicMini\repeat.log` ограничен размером около 128 КБ.
- Изображения и цвета окружения обрабатываются локально. Никакой серверной авторизации Яндекс Музыки не предусмотрено.

## Ограничения и публикация

- Некоторые команды Windows Media Control могут приниматься ОС, но не исполняться клиентом Яндекс Музыки. Повтор остаётся экспериментальным.
- Поведение многомониторных конфигураций с разным DPI проверено не полностью.
- **Права на ресурсы:** в `Assets/ButtonStyles` присутствуют PNG-наборы, переданные для проекта отдельно; перед публичной публикацией проверьте, что у вас есть право распространять каждый набор. Для обложки-заглушки и иконки также подтвердите право распространения.
- Лицензию исходного кода проекта намеренно не назначали. Перед публикацией выберите лицензию и добавьте `LICENSE` — не следует автоматически распространять чужие ресурсы под ней.

Тесты в CI позволяют проверить сборку, но не заменяют проверку поведения живой медиасессии Яндекс Музыки на вашем компьютере.
